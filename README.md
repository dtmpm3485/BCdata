# BCdata

BCSFE用の『にゃんこ大戦争』ゲームデータ。日本版16.0.3の `DataLocal` と `resLocal` を収録しています。

## BCSFEで使う

`game_data_repo` に次のURLを指定します。

```text
https://raw.githubusercontent.com/dtmpm3485/BCdata/main/metadata.json
```

既存バージョンの出典は [fieryhenry/BCData](https://git.battlecatsmodding.org/fieryhenry/BCData) です。

新しいバージョンを追加するときは、アーカイブを `packs/<地域>/<地域>-<バージョン>.tar.xz` に追加し、`metadata.json` の対応する地域にファイルのURLを追記します。
